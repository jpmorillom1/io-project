# Plataforma genérica de Investigación Operativa con tutoría IA

Resuelve problemas de IO (Programación Lineal, Transporte, Redes, y —próximamente— PL Entera,
Programación Dinámica e Inventarios) de cualquier instancia ingresada por el usuario, con un
tutor socrático asistido por IA que orienta el razonamiento sin dar la respuesta final.

## Stack
React + Vite · Spring Boot  Java  · LangChain4j  · ChromaDB (RAG) · PostgreSQL.
